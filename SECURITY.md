# Política de segurança

## Versões com suporte

Enquanto o projeto estiver em fase inicial, somente a versão mais recente da
série `0.1.x` recebe correções. O Waypoint é uma demonstração educacional e não
é uma plataforma pronta para processar dados reais em produção.

## Relatar uma vulnerabilidade

Use o
[relato privado de vulnerabilidade do GitHub](https://github.com/Sheiden1/waypoint-etl/security/advisories/new).
Não abra uma issue pública para falhas que possam expor dados, credenciais ou
permitir execução indevida.

Inclua, quando possível:

- versão ou commit afetado;
- impacto observado;
- passos mínimos com dados sintéticos;
- sugestão de mitigação;
- logs sanitizados, sem documentos, e-mails, tokens ou URLs de banco.

O mantenedor buscará confirmar o recebimento em até sete dias e informará o
andamento conforme a análise. Não há programa de recompensa.

## Uso responsável

Antes de usar o projeto com dados reais, faça sua própria avaliação de
infraestrutura, controle de acesso, retenção, criptografia, backups, legislação
aplicável e LGPD. O repositório não promete conformidade jurídica ou
regulatória.
